# 安全地暂停Windows更新
## Pause Windows Update Safely

#### 介绍
在不影响Windows Update服务的前提下，用极简的方法（几乎）永久暂停windows更新

#### 原理
- 注入注册表，更改字段，修改暂停更新的时长限制
- 26H2：注入注册表，更改字段，修改暂停更新的截止时间



#### 安装教程

1.  从release下载对应reg
2.  双击reg文件，在弹窗中点击确定
3.  enjoy it！

#### 使用说明

- Windows10 和 Windows11 25h2 及其从前的版本：从release下载 延长更新暂停时间10年.reg
- Windows11 26H2 ：从release下载 26H2延长更新暂停至2066.reg
